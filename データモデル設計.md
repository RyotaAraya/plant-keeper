# データモデル設計：PlantKeeper

## ER概要

```
拠点 ──< 設備 ──< 装置・計器 >── サービス（流体）
  │         │         │
  │         │         └──── ラインクラス
  │         │
  │         └──< 定期整備 ──< 整備担当 >── ユーザ
  │
  └──< 倉庫 ──< 在庫（ストック） >── 資材
                                        │
                                        ├──<> 代替品（自己結合）
                                        └──> メーカー

所属会社 ──< ユーザ
部署（3階層: 部→課→チーム） ──< ユーザ
          │
          ├──< 部署異動履歴
          │
          ├──< 設備担当 >── 設備（担当開始日・終了日で履歴管理）
          │
          ├──< 点検記録 ──< 点検項目（チェックリスト）
          │       │
          │       └──> トラブル（不具合連携）
          │
          └──< トラブル ──> 設備 ──> 装置・計器
                  │
                  └──< トラブル対応

チェックリストテンプレート ──< テンプレート項目

資材 ──< 発注履歴
在庫 ──< 入出庫履歴
在庫 ──< 修理履歴

監査ログ（全テーブルの変更を汎用的に記録）
```

※ 添付ファイルは ActiveStorage で管理（専用テーブル不要）

### 2. ユーザ・部署系

#### companies（所属会社）
| カラム | 型 | 説明 |
|---|---|---|
| id | bigint | PK |
| name | string | 会社名 |
| company_type | string | enum: owner（自社） / contractor（協力会社） |
| is_active | boolean | 有効フラグ（デフォルトtrue） |
| created_at | datetime | |
| updated_at | datetime | |

**会社タイプによるビジネスルール：**

| 会社タイプ | 雇用区分の選択肢 | 権限の選択肢 |
|---|---|---|
| owner（自社） | employee（正社員）/ dispatch（派遣社員） | admin（管理者）/ member（一般） |
| contractor（協力会社） | contractor（協力会社）※自動設定 | supervisor（監督者）/ worker（作業員） |

#### departments（部署）
| カラム | 型 | 説明 |
|---|---|---|
| id | bigint | PK |
| name | string | 部署名（計器保全課、電気チーム等） |
| department_type | string | enum: maintenance / operation / environment |
| level | string | enum: division（部）/ section（課）/ team（チーム） |
| site_id | bigint | FK → sites |
| parent_id | bigint | FK → departments（nullable。自己参照で階層構造を表現） |
| created_at | datetime | |
| updated_at | datetime | |

**部署の階層構造：** 部（division）→ 課（section）→ チーム（team）の3階層。`parent_id` による自己参照で親子関係を管理。拠点ごとに独立した部署ツリーを持つ。

#### users（ユーザ）
| カラム | 型 | 説明 |
|---|---|---|
| id | bigint | PK |
| email | string | ログイン用 |
| password_digest | string | 認証用 |
| name | string | 氏名 |
| employment_type | string | enum: employee（正社員）/ dispatch（派遣社員）/ contractor（協力会社） |
| system_role | string | enum: admin（管理者）/ member（一般）/ supervisor（監督者）/ worker（作業員） |
| company_id | bigint | FK → companies |
| position | string | 職位（general_manager / section_manager / team_leader / senior_staff / staff） |
| department_id | bigint | FK → departments（協力会社の場合はnullable） |
| join_year | integer | 入社年 |
| home_prefecture | string | 出身県 |
| previous_company | string | 合併前の所属会社（nullable） |
| is_active | boolean | 在籍フラグ（デフォルトtrue。退職時false、復帰時true に戻す） |
| deactivated_on | date | 退職日（nullable。復帰時もクリアせず履歴として保持） |
| created_at | datetime | |
| updated_at | datetime | |

**旧 role カラムからの分離：** 以前は `role`（worker / contractor / supervisor / maintenance / admin / environment）に雇用区分・所属会社種別・システム権限・部門種別が混在していた。`employment_type`（雇用区分）、`system_role`（システム権限）、`company_id`（所属会社）の3つに分離し、部門種別は `departments.department_type` で管理する設計に変更。

## 簡易化メモ

| 削減したもの | 対応 |
|---|---|
| manufacturer_former_names テーブル | manufacturers.former_names（text）に統合 |
| material_former_part_numbers テーブル | materials.former_part_numbers（text）に統合 |
| material_attachments テーブル | ActiveStorage（has_many_attached）で管理 |
| trouble_response_materials テーブル | trouble_responses.used_materials（text）に統合 |
| maintenance_materials テーブル | scheduled_maintenances.used_materials（text）に統合 |
| price_histories テーブル | orders（発注履歴）で価格推移を兼用 |
| users.role（6値混在） | employment_type + system_role + company_id に分離。部門種別は departments.department_type で管理 |
